# Conversion illustrations

These generated screenshot-style illustrations borrow the black background,
bitmap typography, VGA accents, and function-key strip of the classic GW-BASIC
3.23 screen. They illustrate conversions; the converter itself is a CLI.

- `hello-conversion-v2.png`: source from `examples/hello.rb` (without its comment),
  the converter's emitted BASIC listing, and `Hello, world!` output.
- `countdown-conversion.png`: source from the root README example, its emitted
  BASIC listing, and the countdown output.

Both images were generated with the built-in image generation tool. The full
prompts are retained in [prompts/hello.txt](prompts/hello.txt) and
[prompts/countdown.txt](prompts/countdown.txt), with a final quotation-mark
correction in [prompts/hello-edit.txt](prompts/hello-edit.txt). The supplied GW-BASIC screenshot
was used as a visual style reference. Code text was checked against converter
output before publication.
